🧮 MINI CALCULADORA (+ / -)

Uma mini calculadora de adição e subtração moderna, responsiva e
minimalista, construída usando HTML5, Tailwind CSS e JavaScript.

✨ FUNCIONALIDADES

• ➕ Adição e Subtração: Operações diretas de mais (+) e menos (-).
• ⌨️ Suporte ao Teclado: Digite números e operadores diretamente.
• 🎨 Design Moderno: Estilo escuro (Dark Mode) com Glassmorphism.
• 📱 Responsivo: Funciona bem em telemóveis, tablets e computadores.
• 🧹 Ações Rápidas:
- Botão [C]: Limpa todo o histórico e visor.
- Botão [⌫]: Apaga o último caractere digitado.

🛠️ TECNOLOGIAS UTILIZADAS

• HTML5            - Estrutura da aplicação
• Tailwind CSS     - Estilização moderna via CDN
• JavaScript (ES6) - Lógica de cálculo e eventos de teclado

⌨️ ATALHOS DO TECLADO

[ Tecla ]          [ Ação ]

0 até 9           Digita o número correspondente

            Insere o operador de soma


            Insere o operador de subtração


, ou .            Insere a vírgula/ponto decimal
Enter ou =        Calcula e exibe o resultado
Backspace         Apaga o último número digitado
Esc ou C          Limpa todo o visor
